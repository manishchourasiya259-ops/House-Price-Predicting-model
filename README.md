# House Price Prediction

## About the Project
This project predicts house prices using Machine Learning techniques in Python.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Machine Learning

## Models
- Linear Regression
- Random Forest Regressor
- Gradient Boosting Regressor

## Features
The project uses selected house features, such as living area, lot area, bedrooms, bathrooms, overall quality, year built, and neighborhood, to predict house prices.

## Dataset
Ames Housing Dataset.

## How to Run
1. Clone or download this repository.
2. Install the required libraries:
   `pip install -r requirements.txt`
3. Run the Python script or notebook.
